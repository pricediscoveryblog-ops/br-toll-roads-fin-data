# BR Toll Roads Fin Data

App Streamlit do Price Discovery para concessões rodoviárias brasileiras (federais/ANTT e SP/ARTESP; MG/Artemig no cadastro).

Lê os dados do coletor público `pricediscoveryblog-ops/coletor-concessoes` (branch `dados`). Abas: visão geral e mapa, operacional por SPE e comparação entre SPEs por região, UF, agência ou grupo.

Métricas calculadas no app são cálculo próprio sobre dados abertos; o grupo controlador marcado "validar" vem de conhecimento prévio.
